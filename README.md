NestLedger — a working household budget site for the fictional Bennett family, November 2026, built as a 12-month command center: a dashboard, a searchable 66-transaction ledger with a daily cashflow calendar, 12 editable budget envelopes, 14 bills and subscriptions, 5 savings goals with net worth, an 11-month Year Review with a held-out forecast check (October: $4,590 forecast vs $4,612 actual, 99.5% accurate), a money-leak audit worth $1,147 a year, and five calculators (50/30/20, debt payoff, emergency fund, subscription audit, paycheck planner). Every figure is computed from one ledger — income $7,420, spent $4,920, saved $2,500 (33.7%); year to date $81,000 in, $55,372 out, $25,628 saved (31.6%). Static files only, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Dashboard, Transactions, Budgets, Bills &amp; Subscriptions, Goals, Year Review, Money Leaks and Tools are all hash routes in the top nav.
